# GitHub Upload Steps

1. Create a GitHub repository named `jira-ai-tpm-delivery-project`.
2. Keep the repository public/private according to your submission requirement.
3. Upload all files and folders from this package.
4. Ensure the PPT and `evidence/` folder are included.
5. Commit with message: `Add complete Jira AI TPM delivery project evidence`.
6. Open the repository and verify README, PPT and evidence files.
7. Copy the GitHub repository URL into your Interview Kickstart submission.

## Suggested repository description

Practical Jira-based AI TPM delivery project covering Scrum execution, dependencies, risks, JQL, reporting, dashboarding and TPM interview preparation.
