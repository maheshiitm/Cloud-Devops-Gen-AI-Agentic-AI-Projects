# GitHub Upload Guide — PRD Genie

1. Create a repository named `PRD-Genie` with the visibility required by your trainer.
2. Upload `README.md`.
3. Upload `PRD_Genie_LangFlow_Final_Export.json`.
4. Upload `PRD_Genie_Architecture_Diagram.png`.
5. Upload `architecture_writeup.md` and `architecture_writeup.docx`.
6. Upload `baseline_test_results_FINAL_12of12_PASS.xlsx`, `.csv`, and `.md`.
7. Upload `prompts/`.
8. Upload `screenshots/`.
9. Upload `demo/PRD_Genie_Demo_under_15MB.mp4`.
10. Upload the 25-slide presentation and ROI/business-impact presentation.
11. Upload Q1–Q4 answers and reflection.
12. Before making the repository public, search for secrets: `sk-`, `LANGFUSE_SECRET_KEY`, API keys, passwords, tokens.
13. Open the GitHub README and test every relative link.
14. Submit the public repository URL to the trainer.
