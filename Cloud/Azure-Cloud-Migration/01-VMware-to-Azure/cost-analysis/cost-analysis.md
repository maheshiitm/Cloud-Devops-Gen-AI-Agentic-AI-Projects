# Cost Analysis

Major Azure cost components:
- Virtual Machines
- Managed Disks
- Virtual Network
- Load Balancer
- Storage
- Azure Monitor
- Log Analytics
- AKS where applicable
- Backup and disaster recovery

Optimization:
- Right-size VMs
- Reserved Instances / Savings Plans
- Auto-scaling
- Storage lifecycle policies
- Remove unused resources
- Schedule non-production workloads
